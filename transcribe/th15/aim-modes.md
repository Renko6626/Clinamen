# TH15 mode11 补充

2026-11-08，适用 TH15 v1.00b。其余已有模式沿用共有指南；以下本作静态核对结果覆盖 TH16/TH18 规则书中“mode11速度未解”的限制，不宣称其他作品已验证。

`etAim(id,11)` 的环内第 i 路（i从0开始、总路数N）：

```text
φ = 2π*i/N
angle = alpha + φ
speed = v_layer * (1 - s1 * abs(sin(φ)))
v_layer = s0                                  (M=1)
v_layer = s0 + (s1-s0)*q/(M-1)                (M>1)
```

alpha为 `etAngle` 第一参数，s0/s1为 `etSpeed` 两参数。调制用相对环角，不用最终世界角；本分支不使用 `etAngle` 第二参数。s1同时参与多层速度与方向调制，不能当成普通环的纯末速。

`th15_s7_mb2` 是32路、1层，s0=4、s1=-0.1：速度为 `4 + 0.4*abs(sin(φ))`，相对0/90/180/270度的速度分别4/4.4/4/4.4。可用目标sin和逐颗fire实现，系数用2/5避免先量化0.1；出生ANIM=1按每弹真实初速度后退4倍位移，获准省略的出生表现仍省略。

原生证据见 renkolab 的 `engine/ecl/th15/03-mode11-speed.md`：社区命名 `BulletManager::shoot_one` / `shoot_bullets`，SIMD数学调用、正弦表与FSIN回退路径交叉确认。仅完成静态核对，不等于原作动态对拍。

本卡 `flagSet(76)` 的0x40完整用途仍未定。定向核对的发射、限位和普通体碰路径未使用它；独立卡无敌、没有段外敌与清场交接，不补未知位为人为目标flag，也不把它当作速度调制的前置。此处理只适用本卡现有训练外壳，不外推其全局原生用途。
