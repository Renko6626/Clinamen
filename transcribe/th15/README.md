## 本轮口径

- 目标是借原作攻击丰富合成训练数据。沿用 [TH16 指南](../th16/README.md)和 [TH18 指南](../th18/README.md)的共有语义、目标 API 配方及已批准简化；本轮不要求逐指令重新证明，不因祖传语义的小差异追加原生逆向调查。
- **章节入口、章节状态及相关刷怪门控允许删除。** 准备者选定要保留的编队和发弹循环即可，不必恢复原作章节状态、检查点或重试流程。删除门控后自然保留的敌群和时序可以作为合成数据，不把恢复原作入口列为作者或审核阻塞。
- 游戏内章节较长，仍按独立攻击、编队或有用的发弹循环细切；章节号仅作查找线索，不直接等同一张训练卡。
- `funcSet` 攻击单列给 Sol，不进入默认 QoderCN 批次。2026-11-08 用户已授权按合成训练目标处理：无关音效可省；激光移动、子弹邻近响应等可用任务弹及公开 API 近似，注明差异；无法合理表达时跳过并记录原因，不扩引擎或实体池。无需逐卡重新请求同一许可。各编号以本作已核实现为准，具体功能见下表。

### EX 的本作例外

2026-11-08 独立 agent 已对照 TH15 原生离线导出：609–612 的参数顺序、短式保留字段、18 条 EX 记录及本次源实际使用的 20 种 type 主分派基本对应。二面 REACT → 槽 8 发声 → 反弹 → STEP → 换型的链条未见编号或主要功能错位。STEP c5 为随机偏角，c7 为标量速度扰动；连续角速度属于 type 8 的 s。

复用 [TH16 EX 表](../th16/ex-effects.md)时按以下两处差异覆盖：

- **65536 GOTO**：TH15 只取 a 无条件跳槽，不使用 b 的条件循环计数。当前源唯一一处本来就是跳回槽 2，与此相容。
- **1048576 BRIGHT**：TH15 只区分 a=0／非零，不区分 1／2 两种模式。当前源只用 0／1，未见实际参数冲突。

原生结论在 renkolab 的 `engine/ecl/th15/02-ex-compatibility.md`；[详细报告](../work/th15/ex-audit-20261108/report.md)保留核对位置和范围。本轮为静态对应检查，未全解所有角哨兵、激光消费者或持续效果边界，也未做原作逐帧对拍；其余共有语义继续沿既定口径复用。
