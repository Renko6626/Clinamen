# TH15 弹型合成映射

使用 [touhou-bullets.ecl](touhou-bullets.ecl) 的 `TH15_*` 常量。原 type0–43 依次对应既有现代目录的 `352 + type*16` 行基址；颜色仍传单独色号。不新增引擎槽、资源或 wheel，卡源为 `th15`。

这是一份供合成训练使用的同型词表复用，不宣称 TH15 和 TH16/18 原始资源逐字节相同。2026-11-08 用 renkolab 既有数据读取器对比本作和 TH16 的44项基础半径，全部一致；原表存在 ANM 脚本编号等差异，出生/消弹表现按既定省略口径处理。type33等个别资源索引亦有差异，不把目录索引直接抄成 appearance。

对应名称、目标行基址、有效颜色和基础半径见 [TH16 弹型表](../th16/bullet-types.md)，将常量前缀替换为 `TH15_` 即可。普通色槽不得按16色取模补不存在的颜色；单色火球等沿该表的目标定义使用。目标槽基础半径已与两作来源核对；动态 SIZE/HITBOX 与换型刷新仍按 EX 已有边界处理。

本次证据在忽略目录 `transcribe/work/th15/bullet-mapping-check.json`。TH15 原表基址为 `0x4e0f60`，半径位于记录 `+0x104`，即 `0x4e1064 + type*0x114`；TH16 原表为 `0x49f2e0`。这是表数据读取，没有另起反汇编或 Ghidra 工程。
