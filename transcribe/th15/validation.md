# TH15 单卡外壳与验收

沿用 [TH18 验收附录](../th18/validation.md)的卡格式、开场缓冲和独立无敌外壳，以下本作覆写优先：

- 编号为 `th15_s<1–7>_<w|mb|b><序号>`；道中 w01 起，中Boss和关底将非符/符卡一起按出场顺序编号。
- 元数据 `source="th15"`。普通 rank0–3，Extra rank4；`ranks=[lo,hi]` 是连续区间，不是枚举。
- 目标 `TIME_LIMIT` 和 meta 一致；不套 TH06 的 3000 帧上限。真实时限与波次估计分别标明，开场120帧和尾部按任务单处理。
- 章节入口、状态和刷怪门控允许删除，执行任务所选编队；出生和段外交接按共有许可省略，不补回省略机制。
- 普通激光恒宽近似如实标 `laser_approx=true`；实际曲线激光暂缓。funcSet及死亡发弹等特殊项按任务明示的合成处理执行，不能自行减少发射或缩短寿命。
- 作者只做必要的一次 harness check 与一个代表 rank 的 run；完整机器检查由 [统一执行器](../README.md)负责。written 不代表已验收或收卡。

现有校验器与卡库已将 TH15 纳入现代作来源处理，未另建切分状态机或作品专用验收器。
