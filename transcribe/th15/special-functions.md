## funcSet 的实际功能与近似方向

| id | 本作行为 | Sol 可评估的公开 API 组合 |
|---|---|---|
| 0 | 清当前敌人的回调 | 独立卡不恢复前卡回调，不因此阻塞 |
| 1 | 两类标记弹距离≤20时向被触发弹复制运动字段并把 EX PC 设8 | 把触发后的发声/反弹/STEP/换型链写成任务弹阶段；能否保留相互接近条件须看公开查询能力。缺少邻弹查询时明确近似或跳过，不声称精确复现 |
| 2 | 调用敌周围 F0=64 内对标记0弹消弹 | 由受影响任务弹读取随动圆心，命中距离条件后按公开弹生命周期接口退出；先核可用的跨任务共享坐标，不发明句柄/共享存储接口 |
| 3 | 按激光 laser_id 为0/非零，逐帧给 y 加 F0/F1 | 以公开激光控制或携带激光的移动发射者/任务组合近似；若模型不能携带移动激光，可评估任务弹构成条纹，必须报告几何与时序差异 |
| 4 | 玩家附近的标记1弹速度向量逐帧乘 F0=0.98 | 任务弹读自身/玩家坐标，按距离门控减速；半径组合可作明示近似，不省去实际减速 |

上述是任务交接方向，不是已验证的目标配方。源字段和数值见 [总览](README.md#funcset-清单)与每卡 source；普通内建和任务 owner 规则以同包引擎手册为准，不能依据本表编造接口。

`BossCard4_en` 虽定义了 funcSet3，但五面普通流程没有调用/创建它；`BossCard1_Moon_at` 等未达 helper 同理。按本卡实际闭包处理，不因全文件出现某函数就补入一次执行或累加其效果。

## 死亡发弹与存活路径

死亡回调仅追加危险、存活路径本身仍会发弹时，任务可明确选择无敌、不击杀路径，省略死亡伤害回传并报告差异。只有死亡才发出主弹的编队，单列给 Sol：可评估固定敌龄单次触发源死亡发弹作为合成攻击，触发时点在实现时明确选择和记录；不恢复玩家 DPS，不默默当作普通存活卡。

固定敌龄近似不自动授权拆/删内部危险机制。若源压力依赖击杀且无法选出合理独立攻击，保留边界并建议跳过。四面等死亡回调写 Boss 血量的链不作为无敌训练外壳的阶段推进器。
