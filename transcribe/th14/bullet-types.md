# TH14 弹型合成映射

2026-11-09 用户确认按已核半径与编号差异复用既有现代弹型目录。使用 [touhou-bullets.ecl](touhou-bullets.ecl) 的 `TH14_*` 常量，颜色另传原色号；将整份词表或实际需要的常量放入单卡编译目录。卡来源仍为 `source="th14"`。

映射关系：**TH14 原 type 0–23 对应目标同号；24–42 对应目标 TH18 type 加 1。** 跳过目标 type 24（左旋大星弹），不提供 `TH14_BIG_STAR_L`；原作已有的小左旋星弹仍对应 `TH14_STAR_L`。常量值是目标逻辑行基址，不是原 type 数字。

本词表用于合成训练，沿用现有资源与基础半径，不宣称两作原始纹理、ANM 和所有动态行为逐字节相同；未修改引擎、资源目录或 wheel。

## 原生证据

原生读取路径及全部默认记录统一保存在 renkolab 仓库 `engine/bullet/th14/02-type-defaults.md`；本作样本为 TH14 v1.00b。本页只列转写需要的用法与已批准映射。

- 原生表基址为 TH14 v1.00b `0x4d1e90`，43 条记录，stride `0x114`。
- 记录 `+0x000` 为 `bullet.anm` 主脚本号，`+0x104` 为基础判定半径，`+0x004` 起是 16 组逐色选择数据。43 个主脚本号均已在本作标准 thtk 解码中找到。
- 创建弹与 EX SETSPRITE 均按 type 读表；换型会重新读取新型基础半径。
- type 24–27、38–41 在精灵回调中绕过逐色表，使用 ANM 脚本原有精灵编号，不能按普通 16 色类型套用。

表中半径是原始 f32 的易读表示；精确数值与位模式在 renkolab 的 `local/th14.v1.00b/bullet-types/defaults.json`。

2026-11-09 与 TH18 v1.00a 原生半径字段逐项比较：按相同编号，43 项中 32 项相同，11 项不同（24、26、28–34、36、42）。按本页采用的对应关系“TH14 0–23 保持同号，24–42 对应 TH18 编号加 1”比较，**43/43 的半径 f32 位模式完全相同**。该关系已按用户决定用于合成训练，尚未完成逐型外观／纹理等价验收，不以半径相同代替这项结论。完整计算在 renkolab 的 `local/th14.v1.00b/bullet-types/radius-comparison.json`。
