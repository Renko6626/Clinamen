# 东方躲弹模型命名灵感

记录日期：2026-11-09。状态：尚未定名。

项目通过大规模强化学习训练东方躲弹 AI，目标是在接近人类的观测、反应和操作精度限制下学习躲弹。本次讨论从项目名称逐渐收敛到可承载不同尺寸、不同版本的模型家族名称，再转向更像人名、带二次元角色感的英文或拉丁语风格名称。

## 用户表达的偏好

- 希望名称有格调，偏英文或拉丁文系。
- 名称主要用于模型，需要适合多个尺寸和版本。
- 明确认为 Anima 太大众，不希望采用这种辨识度不足的名字。
- 明确喜欢 Mortalis 的意味，希望寻找类似方向。
- 随后希望更像人名，再进一步希望更二次元。
- 最后希望探索 Mortalis 以外的词根；没有选定最终候选。

讨论中用来解释 Mortalis 的意象是：一个拥有人的局限、会犯错、会被击中的存在，学会在弹幕中生存。后续“有限生命、脆弱之身、余烬、感知、梦境”等方向均由助手据此发散，不等于用户逐项认可。

## 最新一轮候选

除 Favilla 是拉丁原词外，下表其余名称均作为受拉丁词启发的拟名提出，不宣称是古典词汇或已确立的人名。中文叫法、角色气质和项目寓意属于命名创作。拟名也不意味着其拼写从未被他人使用。

| 候选 | 中文叫法 | 来源与命名意象 | 讨论中的评价 |
| --- | --- | --- | --- |
| **Favilla** | 法薇菈 | 拉丁文指热灰、余烬；引申为有限但尚未熄灭的生命 | 原词已具有角色名读感，简洁，有温度与韧性 |
| **Favielle** | 法薇耶尔 | 从 Favilla 改写 | 幻想人物感更强，但比原词多一层加工 |
| **Cadelia** | 卡黛莉娅 | 从 caducus 的声音改写；原词涉及坠落、脆弱、短暂 | 最接近 Mortalis 的有限生命意味，同时更像二次元人名；可简称 Delia／黛莉娅 |
| **Sentelia** | 森缇莉娅 | 从 sentio 改写；原词指感觉、察觉、感知 | 安静、敏锐，与观察和反应的研究主题相接 |
| **Somelia** | 索梅莉娅 | 从 somnium 改写；原词为梦 | 可联想在反复的梦境般练习中学会行动，偏梦幻与东方同人角色气质 |
| **Scintia** | 希缇娅 | 从 scintilla 改写；原词为火花、微光 | 轻巧、灵动，可联系短暂生命和弹幕中的光点 |

这一轮助手较偏向 Cadelia 和 Favilla，用户尚未评价或确认。

词义依据：[favilla](https://www.alatius.com/ls/index.php?l=favillis)、[caducus](https://logeion.org/caducus)、[sentio](https://www.alatius.com/ls/index.php?l=Sentio)、[somnium](https://alatius.com/ls/index.php?l=sommo)、[scintilla](https://alatius.com/ls/index.php?id=42973)。这些来源支持原词含义，不支持拟名的传统词源或角色设定。

## Mortalis 及相近意味

| 候选 | 原义或依据 | 用于模型的意象 |
| --- | --- | --- |
| **Mortalis** | 会死的、凡人的；也可指凡人 | 人类的能力限制与躲弹的生存目标相合；在东方神怪世界中具有明确立场 |
| **Mortalia** | Mortalis 的中性复数，可指人间之事、凡人的遭际 | 凡世；读感更柔和，适合家族名，但比“一个凡人”更抽象 |
| **Superstes** | 尚存的、幸存的，也有见证者之义 | 历经危险仍然存活；与反复尝试的学习过程相接，拼读稍复杂 |
| **Caducus** | 会坠落的；引申为脆弱、短暂、易逝 | 将陨之身，悲剧意味较强 |
| **Fragilis** | 易碎、脆弱 | 技巧发生在脆弱的身体之中，语义直接 |
| **Sospes** | 平安、未受伤、获救 | 穿过危险后安然归来，较温和 |

词义依据：[mortalis／mortalia](https://logeion.org/mortalis)、[superstes](https://alatius.com/ls/index.php?l=superstes)、[caducus](https://logeion.org/caducus)、[fragilis](https://alatius.com/ls/index.php?id=18688)、[sospes](https://classics.andrewgadsden.com/lewisandshort/entry/n44831)。

## 模型家族命名的初步想法

曾提出“家族名＋代际＋尺寸”的形式，例如：

```text
Cadelia-1-S
Cadelia-1-B
Cadelia-2-B
```

另一种形式是按参数量标注，例如 `Cadelia-1-12M`。以上名称、代际、尺寸字母和参数量全部是示例，不代表已批准模型规格或发布规则。

同代修订可考虑 `1.1`；训练步数、随机种子、卡池版本适合放在 checkpoint 文件名或模型说明中。模型尺寸与类人化运行限制分开描述：大模型也可以使用普通人的反应延迟和操作精度，尺寸不直接代表能力限制设定。

项目名与模型名可以共用，也可以分开。曾举过“项目 LIMEN、模型 Anima”的组合，但其中 Anima 已被用户排除，不应在后续工作中作为已定方案沿用。
