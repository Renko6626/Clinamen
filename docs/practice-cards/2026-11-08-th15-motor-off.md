# TH15 关闭运动层对照（2026-11-08）

同一发布模型、129段工作稿、最高难度和seed12345，每段10局，关闭整个运动层后存活由334/1290增至438/1290：**25.89% → 33.95%，提高8.06个百分点，净增104局**。0超时、0执行错误。

运动限制确实造成当前模型在本批攻击上的一部分损失。关闭后仍有51段0/10，不能据此把剩余弱项归给单一原因。这是当前已训练模型的推理期对照，没有检验关闭运动层重新训练后的效果。

## 条件

沿用[发布模型基线](2026-11-08-th15-published-eval.md)的B/Shift K8 u1000 graph7 ONNX，直接运行发布图，不改权重、图输入、弹幕、时限、判定半径、镜像或意图。正篇97段rank3，Extra32段rank4，贪心FP32，每帧决策。保留生产动作表的射击键，无炸弹；无敌训练外壳不靠玩家DPS推进。

基线运动层为hold=[2,6]、delay=[0,2]、slow=true，即方向与低速键各自受随机最短保持和随机延迟约束。本组唯一干预为 **motor.enabled=false**，`EnvWrapper`不建立MotorLayer，模型请求直接执行。实际方向／低速保持历史仍正常更新并送入原模型，没有伪造其输入值。

运行时逐步断言`info.overridden`全为false，最终1,755,350个首次局决策帧的动作改写计数为0。随机弹幕与引擎原有随机过程保持启用；没有将弹幕本身变为确定性版本。同seed／env编号配对的是起始条件，玩家轨迹改变后，自机狙与后续场景可自然分叉。

用户随后明确只做“全部关闭”组，因此取消了刚启动的hold/delay拆分实验，停止其进程，少量不完整记录不进入本次结果。不能从本次数据单独归因于hold或delay。
