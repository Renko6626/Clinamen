# 下一步：逐弹全局场景token替换CNN

更新：2026-11-17。当前已确认方案见[设计](superpowers/specs/2026-11-17-mq4-global-latents-design.md)，实验结果见[结果记录](experiments.md)。

## 已确认的下一阶段

保留近场MQ4（64弹、8激光、4摘要），普通弹采用16维逐弹编码，由32×64维全局场景token读取，再与4个近场摘要联合计算两层；移除密度图与CNN。以无位置任务MQ4作为训练模板，保留操作平滑、贴边惩罚及运动闸，不加入人为安全方向或碰撞答案。

用户要求先保存设计、下一阶段实施。当前尚未实现、短测或训练；已确认结构无需重复讨论，收费实例、短测和训练预算另定，不自动恢复旧Perceiver或替换部署模型。

推进顺序：实现并完成相关本地检查 → 按另行授权的预算做成本短测 → 根据吞吐、缓存/显存和推理成本在512／1024输入中选择，覆盖优先争取1024 → 确认正式训练配置与预算后开训。字段、融合、ONNX和成本边界以设计为准。

数值与比较限制见[实验记录](experiments.md)，当前主要研究依据为[共同弱项分析](practice-cards/2026-11-17-shared-weakness-analysis.md)和[输入/碰撞诊断](practice-cards/2026-11-14-u4000-encoder-diagnosis.md)。四组全败不能证明无解，有闸势场与模型表现轮廓接近也不证明内部机制相同。

## 暂缓的方向

时间记忆仍是候选，尚未选定结构、序列训练或推理状态接口。Top-K行序会变，不能把相邻帧同一行当同一颗弹。增加网络容量不会自动补齐未观测的运动历史；全局场景token本轮也不包含时序记忆。

当前训练起点Hard504／Normal14／Extra150，无Lunatic；难度口径在比较中保留，不把补齐难度作为研究表示的前置条件。工作稿临时参训不等于正式收卡，排除项及已批准简化继续按AGENTS和本作指南执行。

TH14／TH15作者阶段已结束，TH16／TH18明确不做和搁置项不恢复；转写工作只从[生产总览](../transcribe/README.md)及本作指南接续。研究权重、游戏包模型和本地实例历史记录分开核对。
